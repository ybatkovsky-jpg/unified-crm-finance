### 1.8 N+1 → groupBy (`finance/summary/route.ts`)
**Оценка:** ✅ **CORRECT**

```typescript
// Было: 5× aggregate (Promise.all)
// Стало: 1× groupBy
const breakdownRaw = await prisma.transaction.groupBy({
  by: ['categoryId'],
  where: { ...txWhere, categoryId: { in: top5Ids } },
  _sum: { amount: true },
  _count: true,
})
```
- `groupBy` возвращает массив `{ categoryId, _sum: { amount }, _count }`.
- Результаты мапятся через `Map` — O(n) вместо O(n²).
- **Замечание:** если категорий меньше 5 (маловероятно), `slice(0, 5)` вернёт все имеющиеся — `groupBy` с пустым `in: []` вернёт пустой массив. Не баг, но крайний случай.
