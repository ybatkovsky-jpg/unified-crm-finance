## 4. Ключевые выводы анализа

1. **Генерация пакета — на этапе создания проекта** (решение владельца; согласуется с ТЗ: стадия «договор заключён» → создание проекта). Часть документов (акты, ГТ с датой передачи) наполняется данными поздних событий — см. событийную модель в 04.
2. **Документы юридически потребительские** (только физлица, ЗоЗПП). Для юрлиц условные блоки меняют только реквизиты; полноценная B2B-редакция — отдельная задача (05-Б1).
3. **Статика не параметризуется:** реквизиты ООО «Про Мебель», ген. директор, правовые тексты, фиксированные суммы/штрафы, таблица Приложений, примечания бланка — перечислены в реестре (раздел 6).
4. **Макеты xlsx** требуют перевёрстки блоков под циклы и уточнения координат ячеек сумм (05-Е).
5. Формат номеров документов «№ ___ ПМ-26» и связь с номером проекта требуют подтверждения (05-В).

По каждому шаблону в `02_templates/` в конце приведена строка «Сверка с реестром» с перечнем номеров используемых плейсхолдеров. Сводно:

| ДМ | 1–4, 15–23, 25–39, 43, 62, 69–73 |
| АВР | 3, 4, 7, 9, 15–16, 25–39, 43, 60, 69, 85 |
| АПП | 1, 2, 8, 15–16, 17–23, 25–39, 76–80 |
| ГТ | 1, 5, 8, 10, 15–16, 41, 43, 74–75 |
| БЗ | 2, 5, 15, 23–24, 36, 41, 43, 45–57, 61 |
| СП | 1, 2, 6, 15, 23, 36, 41, 43, 45, 58–59, 63, 65 |
| ПАМ | 11 |

**Проверка полноты:** каждый плейсхолдер из реестра используется хотя бы в одном шаблоне, кроме служебных/резервных: № 13 (город — оставлен статикой «г. Хабаровск», зарезервирован), № 27–35/36–39 (используются только при `Client.type = legal/ip`), № 44, 64, 66–68/87 (расчётные/опциональные). Плейсхолдеров «без источника» нет — все недостающие источники помечены в реестре ⚠ и вынесены в 05.

## 6. Документы, отсутствующие в комплекте

(подробно — 05-К): Перечень недостатков Товара (выставочный образец), Бланк замера (внутренний), счёт на оплату (юрлица/безнал), B2B-редакции договоров, при необходимости — бланк доверенности представителя.

## 7. Допущения (зафиксированы)

1. «Дата заказа» = дата создания проекта = дата ДКП (используется `Order.date`/`Doc.saleContract.date`); если это не так — 05-Ж3.
2. Даты подписания в таблицах реквизитов = дата соответствующего документа.
3. Признак НДС единый для продавца (настройка) с возможностью переопределения в заказе — 05-З1.
4. Итоговые суммы и пропись считаются генератором; в исходных xlsx формулы отсутствуют.
5. Подписи печатаются пустыми (рукописные) до решения по УКЭП — 05-Б4.
