## 4. Ключевые выводы анализа

1. **Генерация пакета — на этапе создания проекта** (решение владельца; согласуется с ТЗ: стадия «договор заключён» → создание проекта). Часть документов (акты, ГТ с датой передачи) наполняется данными поздних событий — см. событийную модель в 04.
2. **Документы юридически потребительские** (только физлица, ЗоЗПП). Решение владельца (05-Б): применяются для физических лиц; для юрлиц и ИП разрабатываются отдельные B2B-формы.
3. **Статика не параметризуется:** реквизиты ООО «Про Мебель», ген. директор, правовые тексты, фиксированные суммы/штрафы, таблица Приложений, примечания бланка — перечислены в реестре (раздел 6).
4. **Макеты xlsx** требуют перевёрстки блоков под циклы и уточнения координат ячеек сумм (05-Е).
5. Нумерация определена (05-В): единый номер пакета `ПМ2026-NNNNN`, договор = проект, приложения наследуют номер.

3. Признак НДС единый для продавца (настройка) с возможностью переопределения в заказе — 05-З1.

## 9. Решения владельца (обратная связь по 05)

Зафиксированы в `05_owner_questions.md` и внесены в реестр/шаблоны/логику/реализацию:

- **Данные:** паспортные данные — в CRM (05-А1); пол — по отчеству (05-А2); email — поле есть, пустое не выводится (05-А3); телефон — один общий (05-А4).
- **Юридика:** юрлица/ИП — отдельные **B2B-формы** (05-Б1/Б2), ИП оформляется как юрлицо (05-Б3); подписи — вручную или по ЭДО (05-Б4).
- **Нумерация:** единый номер пакета `ПМ2026-NNNNN`, договор = проект (05-В1); приложения наследуют номер (05-В2); в ГТ: первый номер — ДКП, второй — БЗ (05-В3).
- **Макеты xlsx:** БЗ — ИТОГО в G29 (05-Е1), параметры перевёрстаны «подпись | поле» (05-Е4), вставка строк разрешена (05-Е5), подпись под эскизом не нужна (05-Е6); СП — позиции по одной строке (05-Е2), ИТОГО F28 / «Со скидкой» F29 (05-Е3).
- **Даты:** реальные даты генерации (05-Ж1); Правила — дата передачи Товара (05-Ж2); ГТ: дата заказа = дата ДКП, дата передачи = `Doc.actAcceptance.date` (05-Ж3).
- **НДС/оплата:** УСН «доходы-расходы» → «НДС не облагается» по умолчанию (05-З1); бонус дизайнера 10 % в документах не выводится (05-З2); счёт — через 1С (05-З3).
- **Репозиторий:** исходные `documents/*_2026.docx` закоммичены и запушены (05-И1); правки юридических текстов согласовывает владелец (05-И2).
- **Открытые вопросы:** 05-Д1 (адреса), 05-К1 (Перечень недостатков Товара), 05-К2 (Бланк замера), 05-К5 (доверенность), уточнение фактического состава полей CRM при интеграции (05-Г).
