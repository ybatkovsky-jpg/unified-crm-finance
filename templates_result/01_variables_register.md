# 01. Реестр переменных документов ООО «Про Мебель»

**Назначение:** единый перечень всех динамических полей для автоматической генерации документов из карточки клиента и заказа (проекта) самописной CRM.

**Сокращения документов:**
ДКП — Договор купли-продажи мебели по индивидуальному заказу (`sale_contract_2026.docx`);
ДМ — Договор возмездного оказания услуг по сборке и установке мебели (`assembly_service_contract_2026.docx`);
АВР — Акт выполненных работ (`works_acceptance_act_2026.docx`);
АПП — Акт приёма-передачи Товара (`goods_transfer_act_2026.docx`);
ГТ — Гарантийный талон (`warranty_card_2026.docx`);
БЗ — Бланк-заказа (`order_form_2026.xlsx`);
СП — Спецификация заказа (`specification_2026.xlsx`);
ПАМ — Памятка покупателю (`buyer_memo_2026.docx`);
ПРАВ — Правила и условия эффективного и безопасного использования мебели (`usage_rules_2026.docx`).

**Соглашения:**
- Синтаксис плейсхолдеров — Jinja2/docxtpl: `{{переменная}}`, условия `{% if %}…{% endif %}`, циклы `{% for %}…{% endfor %}`.
- ФЛ — физическое лицо; ЮЛ — юридическое лицо; ИП — индивидуальный предприниматель (оформление по правилу ЮЛ с ОГРНИП либо как ФЛ — настраивается, см. 03).
- «Обяз./Опц./—»: обязательно / опционально (при отсутствии остаётся подчёркивание для ручного заполнения) / не применяется.
- Флаг «⚠ уточнить» в колонке «Примечание» означает: данных в исходниках/ТЗ недостаточно — вынесено в `05_owner_questions.md`.
- Формат дат — как в оригинале: ««ДД» месяц(род. п.) ГГГГ г.», например ««05» мая 2026 г.».
- Формат сумм: цифрами с разделителем тысяч (пробел) + прописью по правилам русского языка там, где требует оригинал («(…) рублей __ копеек»).
