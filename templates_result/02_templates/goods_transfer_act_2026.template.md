# Шаблон: «Акт приёма-передачи Товара»
> **Применение (решения владельца, 05):** потребительская форма — для **физических лиц**. Юрлица и ИП оформляются отдельными B2B-формами (05-Б1/Б2/Б3, см. 03); условные ветки «юрлицо/ИП» в этом файле приведены как справочные и в этой форме не активируются. Подписи — вручную или по ЭДО (05-Б4). Номер документа по умолчанию = единый номер пакета `ПМ2026-NNNNN` (05-В1/В2).

**Файл-источник:** `documents\goods_transfer_act_2026.docx`
**Логическое место в пакете:** Приложение № 4 к ДКП; генерируется/дополняется на событии «передача товара» (`Doc.actAcceptance.date`), дата и отметки приёмки на момент проекта неизвестны.
**Метод конвертации:** замена заглушек в копии исходного .docx; статика — без изменений.
**Используемые плейсхолдеры:** № 1, 2, 8, 13, 15, 16, 17–23, 25–39, 76–80; статика С1–С4, С9.

### Пункт 2 (P6) — видимые недостатки (выбор из оригинала)

Оригинал: `…Видимые недостатки (дефекты) при передаче: не обнаружены / обнаружены (нужное подчеркнуть): ___<подчёркивание>___.`

```
…Видимые недостатки (дефекты) при передаче:
{% if Order.acceptance.defectsFound %}обнаружены (нужное подчеркнуть — подчёркнуто «обнаружены»){% else %}не обнаружены (нужное подчеркнуть — подчёркнуто «не обнаружены»){% endif %}:

```

> Технически: в печатной форме подчёркивается выбранный вариант («не обнаружены» или «обнаружены»), свободное место оставляется под описание либо заполняется `Order.acceptance.defectsText`.
