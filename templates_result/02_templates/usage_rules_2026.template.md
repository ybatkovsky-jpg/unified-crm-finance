# Шаблон: «Правила и условия эффективного и безопасного использования мебели»

**Файл-источник:** `documents\usage_rules_2026.docx`
**Логическое место в пакете:** Приложение № 7 к ДКП; выдаются при передаче Товара.
**Метод конвертации:** замена заглушек в копии исходного .docx.
**Используемые плейсхолдеры:** № 12 (`Doc.rules.signDate`), 15–23 (физлицо), 25–39 (юрлицо/ИП, условный блок); статика С1–С4, С9.

---

## Анализ документа

Правила — большой **статичный технический документ** (условия эксплуатации и ухода: общие условия, свет, температура, влажность, агрессивные среды, мебель для сидения/лежания, корпусная мебель, покрытия, профилактика — абзацы P5–P56). Вся правовая/техническая часть берётся из оригинала **без изменений**.

Динамические элементы — только в шапке и в таблице подписей:
1. титульная дата (P1);
2. блок покупателя в таблице реквизитов (T1, правая колонка);
3. даты подписания (T1).

### Шапка (P1)

Оригинал: `«_____» ________ 2026г.`

```
{{ Doc.rules.signDate|rus_date_nobrackets }}
```
> Формат титульной даты без обрамляющих кавычек дня: «05» мая 2026 г. — сверять с оригинальной вёрсткой (вариант `rus_date`). Содержимое после шапки (P2–P56) — статика.

### Таблица реквизитов и подписей (T1)

Левая колонка — реквизиты и подпись ООО «Про Мебель» (С1): оставляется без изменений, кроме даты подписи.

Правая колонка (в оригинале блок физлица) заменяется условным блоком:

```
{% if Client.type == 'legal' or Client.type == 'ip' %}
Наименование: {{ Client.legal.shortName }}
{% if Client.legal.fullName %}Полное наименование: {{ Client.legal.fullName }}{% endif %}
ИНН/КПП: {{ Client.legal.inn }} / {{ Client.legal.kpp or '—' }}
ОГРН: {{ Client.legal.ogrn or Client.legal.ogrnip }}
Юридический адрес: {{ Client.legal.legalAddress }}
Тел.: {{ Client.phone }}
{% else %}
ФИО: {{ Client.fullName }}
Паспорт: серия {{ Client.passport.series }} номер {{ Client.passport.number }}
Выдан: {{ Client.passport.issuedBy }}
Дата выдачи: {{ Client.passport.issueDate|rus_full_date }} Код подразделения: {{ Client.passport.departmentCode }}
Адрес: {{ Client.regAddress }}
Тел.: {{ Client.phone }}
{% endif %}
_________________________ /
{{ ' ' if not Client.type in ('legal','ip') else Client.legal.signatoryName }}
{{ Doc.rules.signDate|rus_date }}
```

> Даты слева (Продавец) и справа (Покупатель) — дата подписания Правил (выдачи при передаче Товара). Какая именно дата ставится на титуле и в подписях — см. вопрос 05-Ж; по умолчанию во всех местах `Doc.rules.signDate`.
