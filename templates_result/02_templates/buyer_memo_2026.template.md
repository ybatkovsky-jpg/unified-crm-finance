# Шаблон: «Памятка покупателю мебели»

**Файл-источник:** `documents\buyer_memo_2026.docx`
**Логическое место в пакете:** Приложение № 6 к ДКП; выдаётся при заключении Договора.
**Метод конвертации:** замена заглушек в копии исходного .docx.
**Используемые плейсхолдеры:** № 11 (`Doc.memo.signDate`); статика С1, С4, С8.

---

## Анализ документа

Памятка — **почти полностью статичный** информационный документ (10 пунктов требований к помещению и сборке). Именование покупателя в тексте не используется — только подписи. Динамическим является один элемент — дата в строке подписи.

### Текст (P1–P14, таблица T1)

- P1 «ПАМЯТКА ПОКУПАТЕЛЮ МЕБЕЛИ», P2 «ООО «Про Мебель», г. Хабаровск, тел. 8 962-563-19-70», P4–P14 (пункты 1–10) — **статика, берётся из оригинала без изменений** (С4). Никакие тексты правил не параметризуются.

### Таблица подписей (T1)

Оригинал:
```
| С памяткой ознакомлен(а), с требованиями согласен(а): | _________________ / ___________________ / |
| «___» ______________ 2026 г.                          |                                              |
```

Замена:
```
| С памяткой ознакомлен{% if Client.gender == 'f' %}а{% endif %}, с требованиями согласен{% if Client.gender == 'f' %}а{% endif %}: | _________________ / ___________________ / |
| {{ Doc.memo.signDate|rus_date }}                                                                                                    |                                              |
```

> Значение `Doc.memo.signDate` = дате заключения Договора (дата выдачи памятки, по Прил. № 6). Подпись покупателя — рукописная, печатается пустой.
