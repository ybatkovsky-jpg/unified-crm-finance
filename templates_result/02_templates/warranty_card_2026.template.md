# Шаблон: «Гарантийный талон»
> **Применение (решения владельца, 05):** потребительская форма — для **физических лиц**. Юрлица и ИП оформляются отдельными B2B-формами (05-Б1/Б2/Б3, см. 03); условные ветки «юрлицо/ИП» в этом файле приведены как справочные и в этой форме не активируются. Подписи — вручную или по ЭДО (05-Б4). Номер документа по умолчанию = единый номер пакета `ПМ2026-NNNNN` (05-В1/В2).

**Файл-источник:** `documents\warranty_card_2026.docx`
**Логическое место в пакете:** Приложение № 5 к ДКП; выдаётся при передаче Товара (поля «дата передачи» и подписи заполняются на событии передачи).
**Метод конвертации:** замена заглушек в копии исходного .docx; гарантийные обязательства (пп. 1–7) — статика.
**Используемые плейсхолдеры:** № 1, 5, 8, 10, 15, 16, 41, 43, 74, 75; статика С1–С4, С9.

## Текст шаблона (динамические места)

```

Гарантия действительна только при наличии правильно и полностью заполненного гарантийного талона, заверенного подписями Сторон.
```

## Карта замен

| Место в оригинале | Заглушка | Замена |
|---|---|---|
| P1 | `№ ______` | `{{ Doc.guarantee.number }}` |
| T1 R1 | пустая строка после «Покупатель (Ф.И.О.):» | `Client.fullName` / юрлицо-блок |
| T1 R2 | пустая строка | `{{ Order.deliveryAddress }}` |
| T1 R3 | пустая строка | `{{ Order.productName }}` (+артикул) |
| T1 R4 | `______ / № ______ ПМ-26` | № ДКП и № БЗ = единый номер пакета (05-В3) |
| T1 R5 | `«___» ____________ 2026 г.` | `{{ Order.date|rus_date }}` |
| T1 R6 | `«___» … 20__ г.` | `{{ Doc.actAcceptance.date|rus_date }}` |
| T2 R2 правая колонка | «ознакомлен(а)» + подписи | родовая форма по `Client.gender` |
| T2 R3 | даты | `{{ Doc.actAcceptance.date|rus_date }}` |

> Примечание: дата выдачи талона совпадает с датой передачи Товара (по ДКП п. 5.3/Прил. № 5) — используется `Doc.actAcceptance.date`. Если талон выписывается в иной день — ввести отдельное поле (вопрос 05-Ж).
