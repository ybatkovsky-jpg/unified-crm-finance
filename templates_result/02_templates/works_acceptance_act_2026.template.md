# Шаблон: «Акт выполненных работ (оказанных услуг)»

**Файл-источник:** `documents\works_acceptance_act_2026.docx`
**Логическое место в пакете:** подписывается по завершении монтажа (Приложение к ДМ); генерируется на событии «завершение монтажа» (`Doc.actWorks.date`).
**Метод конвертации:** замена заглушек в копии исходного .docx; статика — без изменений.
**Используемые плейсхолдеры:** № 3, 4, 7, 9, 13, 15, 16, 25–39, 43, 60, 69, а также расчётное `Order.worksTotal` (дополнение к реестру, см. 01 §7).

```
ООО «Про Мебель», именуемое в дальнейшем «Исполнитель», в лице генерального директора
Батьковского Юрия Сергеевича, действующего на основании Устава, с одной стороны, и

{% else %}

следующие Услуги по сборке и установке (монтажу) мебели по адресу: {{ Order.deliveryAddress }}.
```

### Таблица работ (T2) — цикл по строкам

Оригинал — колонки: `№ п/п | Наименование работ (услуг) | Ед. изм. | Кол-во | Цена, руб. | Сумма, руб.`; строки 2–4 — позиции (в образце строка 2 заполнена примером «Сборка и установка (монтаж) кухонного гарнитура»), строка 5 — `ИТОГО`.

```
№ п/п | Наименование работ (услуг) | Ед. изм. | Кол-во | Цена, руб. | Сумма, руб.
{% for w in Order.works %}
{{ loop.index }} | {{ w.name }} | {{ w.unit }} | {{ w.qty }} | {{ w.price|fmt_roubles }} | {{ w.amount|fmt_roubles }}
{% endfor %}
| | ИТОГО: | | | | {{ Order.worksTotal|fmt_roubles }} |
```

> Позиции берутся из фактического состава работ монтажа (этап «завершение монтажа»). Образец-строка «Сборка и установка (монтаж) кухонного гарнитура» из оригинала в шаблон не копируется — это пример данных, а не текст.

### Пункт P5 — сумма по акту

Оригинал: `Всего оказано услуг на сумму: ______________ (____________________________________) рублей __ копеек, НДС не облагается / в том числе НДС (нужное указать).`

```
Всего оказано услуг на сумму: {{ Order.worksTotal|fmt_roubles }} ({{ Order.worksTotal|sum_words }})
рублей {{ Order.worksTotal|fmt_kopeks }} копеек, {% if Order.nds %}в том числе НДС{% else %}НДС не облагается{% endif %}.
```

Без изменений (С4): «Услуги оказаны в полном объёме…» и «Акт составлен в двух экземплярах…».
