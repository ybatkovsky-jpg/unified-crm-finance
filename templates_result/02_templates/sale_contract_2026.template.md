# Шаблон: «Договор купли-продажи мебели по индивидуальному заказу»

**Файл-источник:** `documents\sale_contract_2026.docx`
**Логическое место в пакете:** основной документ; Приложения № 1–7 (БЗ, СП, ДМ, АПП, ГТ, Памятка, Правила) — отдельные файлы пакета.
**Метод конвертации:** в копии исходного .docx программно заменяются только заглушки (см. «Карту замен» в конце); весь остальной текст берётся из оригинала без изменений — юридический смысл сохраняется 1:1.
**Синтаксис:** Jinja2/docxtpl. Даты — фильтр `rus_date` (→ ««05» мая 2026 г.»), суммы — `fmt_roubles` (→ «1 234 567»), `fmt_kopeks` (→ «00»), пропись — `sum_words`.

**Используемые плейсхолдеры (по реестру 01):** № 1, 2, 13, 15, 16, 17–23 (физлицо), 25–39 (юрлицо/ИП), 66–69; статика С1–С4, С6, С9.

## Текст шаблона (динамические места — с плейсхолдерами)

### Шапка (замены в строках оригинала P1, таблица T1)

```
ДОГОВОР № {{ Doc.saleContract.number }} купли-продажи мебели по индивидуальному заказу

| г. Хабаровск | «{{ Doc.saleContract.date|rus_date_day }}» {{ Doc.saleContract.date|rus_date_month }} {{ Doc.saleContract.date|rus_date_year }} г. |
```

*(Практически: весь заголовок даты печатается одной строкой `{{ Doc.saleContract.date|rus_date }}`, где rus_date возвращает ««05» мая 2026 г.» целиком, включая кавычки.)*

### Пункт введения (P3) — условный блок «Покупатель»

Оригинал: `…с одной стороны, и ___<пустая строка>___, именуемый(ая) в дальнейшем «Покупатель», с другой стороны, совместно именуемые «Стороны», заключили настоящий Договор…`

Заменяется (весь блок от «и » до «с другой стороны»):

```
и
{% if Client.type == 'legal' or Client.type == 'ip' %}
{{ Client.legal.shortName }} ({{ Client.legal.fullName }}), в лице {{ Client.legal.signatoryPosition }}
{{ Client.legal.signatoryName }}, действующего на основании {{ Client.legal.signatoryBasis }},
именуемое в дальнейшем «Покупатель», с другой стороны,
{% else %}
{{ Client.fullName }}, именуем{% if Client.gender == 'm' %}ый{% else %}ая{% endif %}
в дальнейшем «Покупатель», с другой стороны,
{% endif %}
```

> Юридическая оговорка: текст ДКП составлен как потребительский (п. 1.3 — только личные нужды; ЗоЗПП). Для ЮЛ полная редакция требует согласования — см. 03 и 05-Б. Условный блок выше заменяет только реквизитную часть введения, правовые пункты не меняются.

### Разделы 1–3 (P4–P14) — статика

P4–P14 без изменений (С4). Таблица Приложений T2 — статика (С6), строки не параметризуются:
`1 Бланк-заказ (с эскизом и техническим описанием) — подписывается при заключении Договора; 2 Спецификация заказа; 3 Договор возмездного оказания услуг по сборке и установке Товара — заключается при заказе услуги; 4 Акт приёма-передачи Товара; 5 Гарантийный талон; 6 Памятка покупателю; 7 Правила и условия эффективного и безопасного использования мебели`.
> Наличие/отсутствие Приложения № 3 в комплекте управляется `Order.hasAssembly` на уровне сборки пакета (см. 04), а не текстом таблицы.

### Пункт 4.1 (P16) — цена договора

Оригинал: `…составляет ________________ (________________________________________) рублей __ копеек, НДС не облагается / в том числе НДС (нужное указать).`

```
…составляет {{ Order.contractPrice|fmt_roubles }} ({{ Order.contractPrice|sum_words }}) рублей
{{ Order.contractPrice|fmt_kopeks }} копеек, {% if Order.nds %}в том числе НДС{% else %}НДС не облагается{% endif %}.
```

### Разделы 4.2 – 14 (P17–P89) — статика

P17–P89 без изменений (С4, С5). Никакие фиксированные суммы (аванс 70/30 %, 60 раб. дней, 4 000 руб., 0,5 %/день, 10 дней и пр.) не параметризуются.
