## 05-Б. Юридические аспекты (критично)

1. **05-Б1. B2B-редакции договоров.** ✅ Ответ: необходимость есть. → **Решение:** юридические лица оформляются отдельными B2B-формами (без ЗоЗПП, с НДС/счётом). B2B-редакции ДКП/ДМ/актов — отдельная задача: подготовить редакции (владелец/юрист) и добавить в комплект вторым набором шаблонов. Потребительские формы в `02_templates/` применяются для физических лиц.
2. **05-Б2. Подписи-лейблы при юрлице.** ✅ Ответ: для юрлиц — отдельная форма документов. → Совпадает с 05-Б1: в потребительских формах лейблы не меняются; B2B-формы верстаются со своими лейблами («Заказчик (наименование):» и т.п.).
3. **05-Б3. Режим ИП.** ✅ Ответ: «ИП это юрлицо по идее». → **Решение:** ИП оформляется по B2B-набору форм как юрлицо: ОГРНИП вместо ОГРН, КПП не выводится, подписант — ИП, основание — свидетельство ОГРНИП / лист записи ЕГРИП.
4. **05-Б4. УКЭП.** ✅ Ответ: подписываются вручную или по ЭДО. → Поля подписей печатаются пустыми (рукописная подпись); интеграция ЭДО — отдельная задача (в шаблонах/генераторе предусмотреть слоты подписей).

## 05-В. Нумерация документов

1. **05-В1.** ✅ Ответ: «ПМ = ПРО МЕБЕЛЬ, 2026 — год, дальше сквозная нумерация, договор и проект должны иметь один номер». → **Схема:** единый сквозной номер года `ПМ2026-NNNNN` (аналог номера проекта по ТЗ); **номер договора = номер проекта**. БЗ и СП печатают тот же номер (без хвоста «ПМ-26» в шапке — он заменяется единым номером).
2. **05-В2.** ✅ Ответ: «Все документы кроме договора — приложения к договору со сквозной нумерацией». → Номера приложений — по таблице Приложений ДКП (№ 1–7). Номера в шапках АВР/ГТ/БЗ/СП по умолчанию = единый номер договора/проекта (при необходимости отдельной серии актов/талонов — настройка, см. 04 §2).
3. **05-В3.** ✅ Ответ: подтверждаю. → В ГТ первый номер — № Договора купли-продажи (= единый номер), второй — № Бланка-заказа (= тот же единый номер пакета).
